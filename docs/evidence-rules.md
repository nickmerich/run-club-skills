# Evidence rules

Every skill in this library labels what it says. Use these four labels in plans, decks, and recaps.

| Label | Means | Example |
|-------|-------|---------|
| **VERIFIED** | Checked against a record you can point to: check-in data, signed agreement, bank deposit, permit letter, the artist's own post. | "62 people checked in (check-in export, 9:14 AM)." |
| **REPORTED** | Someone told you. Useful, not proof. Say who. | "Artist's manager reports a 4,000-person local email list." |
| **ASSUMPTION** | A planning number you chose. Say why. | "Assume 55% of RSVPs show up (our last three free events averaged 50 to 60%)." |
| **ASK / PROPOSED** | Something you want, not something you have. | "Proposed: brand covers coffee for 150." |

## Counts that are never interchangeable

- Followers / list size → interested people → RSVPs or tickets claimed → checked in → finished → came back.
- Pipeline value → verbal yes → signed agreement → invoice → paid.
- Drafted → approved → sent → delivered → replied.

## Hard rules

- Missing data is **UNKNOWN**, never zero and never a pass.
- Don't round up. "About 100" from 87 check-ins is "87."
- Never write a testimonial, quote, or story someone didn't give you. Paraphrase only with permission.
- Projections show their inputs. If you can't show the inputs, it isn't a projection.
