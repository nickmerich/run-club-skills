# Milestones and Streaks

Recognize the habit, not the pace.

## Rules

- **Count check-ins.** Walking, run/walking, buddying, sweeping, and volunteering all count.
- **Lifetime counts never reset.** Missed weeks don't erase anything.
- **Streaks are optional and forgiving.** If you use them, allow a grace week, and never shame a broken streak.
- **Personal counts are private by default.** Public posts show totals ("4 people hit 10 runs this month") and names only with permission.
- Only count from records you trust. Don't backfill from memory.

## Tiers (example)

| Runs | Name idea | Recognition |
|------|-----------|-------------|
| 5 | First chapter | Personal note |
| 10 | Regular | Shout in the circle (if OK), small token |
| 25 | Crew | Patch, sticker, or a hat |
| 50 | Anchor | Asked what they'd change about the club |
| 100 | Lifer | Something lasting and personal |

Recognition that gives access or voice (lead a route, pick the playlist, help name things) lasts longer than stuff.

## Weekly

Run the scorecard. List who crosses a tier this week. Draft the private note first; public mention only with consent.
